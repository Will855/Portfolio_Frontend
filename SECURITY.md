# Security Policy

## Supported Versions

This is a personal portfolio project. Only the latest version on the `main` branch is actively maintained.

| Version | Supported |
| ------- | --------- |
| `main`  | ✅ Yes    |
| Others  | ❌ No     |

## Reporting a Vulnerability

If you discover a security vulnerability in this project, please **do not open a public GitHub issue**.

Instead, report it privately by contacting me directly:

- 📧 **Email:** wilmerjoselynchestaba@gmail.com
- ⏱ **Response time:** I aim to respond within 48–72 hours.

Please include the following in your report:
- A clear description of the vulnerability.
- Steps to reproduce it.
- The potential impact you believe it could have.

I take security seriously and will address any confirmed vulnerabilities as quickly as possible. Thank you for helping keep this project safe.
